# Toei GO — English store listing

## App name

Toei GO

## Short description

Unofficial route planner for trips using Toei Bus and Toei Subway only

## Full description

Toei GO is an independently developed, unofficial app for finding routes that use Toei transportation services without using JR or private railway lines.

It focuses on Toei Bus and Toei Subway routes. The app also supports your trip with features such as showing how many stops remain while riding, a “get off next” reminder, finding places you can reach without transfers, and sharing group outing plans.

It can also be useful for people who use the Toei Transportation Pass for Persons with Mental Disabilities, the Tokyo Silver Pass, or similar programs and want to travel using Toei transportation.

【Main features】

- Route search focused on Toei transportation
- Riding guidance showing remaining stops and a “get off next” reminder
- Find places reachable without transfers
- Group outing plans and trip itineraries
- Discover places around stations and bus stops

For everyday travel or a trip somewhere new,
Toei GO helps you discover more of Tokyo using Toei transportation.
